# BetterTipTac

TipTac engine for WoW Forever (Camelot). Slash: `/btt`.

Install the four folders from the release zip into `Interface/AddOns`:

- BetterTipTac
- BetterTipTacItemRef
- BetterTipTacOptions
- BetterTipTacTalents

Disable TipTac, TipTacItemRef, TipTacOptions, TipTacTalents, and TipTacEverlight. Do not run both suites.

`/btt` opens options. SavedVariables: `BetterTipTac_Config`.

Backdrop, layout presets, and colors use TipTac's default `SetBackdrop` border so those options apply unchanged.
